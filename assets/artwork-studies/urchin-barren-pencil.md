# Urchin barren pencil study

AI-assisted habitat illustration for Resilience Across Scales. The anatomy and habitat reference was `public/images/urchin-barron.jpg`; `giant-kelp-pencil.png` guided the colored-pencil style. The drawing does not document a particular site or survey.

Version 2 (`urchin-barren-pencil-v2.png`) uses [Jim Knowlton's Crook Point photograph](https://www.fisheryfriendlyclimateaction.org/blog/el-nino-2026) for urchin color and exposed rock, and [Steve Lonhart's NOAA photograph](https://sanctuaries.noaa.gov/news/2026/restoring-balance.html) for the wider reef view and patchy distribution. It combines features from both references and is not a rendering of either site. The Research overview uses the compressed version 2 JPEG.
