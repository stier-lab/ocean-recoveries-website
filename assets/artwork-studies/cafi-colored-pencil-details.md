# CAFI colored-pencil details

These AI-assisted illustrations use an earlier elkhorn drawing for style and the flagged CAFI photos for anatomy. The companion coral image, `pocillopora-with-coral-associates-v3.png`, is a composite. Adobe Stock 260730256 provided the colony shape; the photo's locality is unverified.

- `harpiliopsis-spinigera-pencil.png`: flagged reference 03A.
- `alpheus-lottini-pencil.png`: flagged reference 01A.
- `galathea-pencil.png`: flagged reference 06A. The photo is labeled Galathea mauritiana in the archive; the page uses Galathea.

The reference IDs, source paths, and checksums are recorded in the local `assets/cafi-species/preferred-photos.csv`. The Coral Reefs page uses smaller JPEG copies in `public/images/research/`. These are illustration studies, not identification plates.
